# brat api — web

The deployable web API + tutorial homepage version of brat api.

## Run locally

```bash
npm install
npm start
```

Then open `http://localhost:3000`.

## Deploy to Vercel

Import this folder as the **Root Directory** on [vercel.com/new](https://vercel.com/new) — no configuration needed, `vercel.json` handles routing.

## Endpoints

```
GET /brat?text=Hello%20World
GET /bratvideo?text=Hello%20World
```

See the full guide in the repository root: [`../README.md`](../README.md) and [`../TUTORIAL-HOW-TO-USE.md`](../TUTORIAL-HOW-TO-USE.md).
