brat api

Turn any text into a brat-style square cover image or word-by-word reveal video. Two endpoints, zero setup, works with any language over plain HTTP.

02 · reference

two endpoints. that's it.

GET/brat?text=

Returns a single 1000×1000 PNG image, styled like the classic brat cover. Spaces in the text can be a literal space or %20 — both work.

paramtypedefaultdescription
textstring—required. the text to render
themeblack · white · greenwhitebackground / text colors
blur0 · 1 · 2 · 30text blur amount
GET/bratvideo?text=

Returns an MP4 (or GIF) that reveals the text word-by-word, the same effect as the original brat generator video.

textstring—required. the text to render
themeblack · white · greenwhitebackground / text colors
blur0 · 1 · 2 · 30text blur amount
formatmp4 · gifmp4output file format
03 · copy & paste

real, working examples

# image, spaces as %20
curl "https://your-domain.com/brat?text=Hello%20World&theme=green" --output brat.png

# image, spaces as literal " " (also works)
curl "https://your-domain.com/brat?text=Hello World&theme=black&blur=1" --output brat.png

# word-by-word reveal video
curl "https://your-domain.com/bratvideo?text=so this is brat&format=mp4" --output brat.mp4

# plain HTML - any language, no library needed
<img src="https://your-domain.com/brat?text=so%20original" />

05 · getting started

run your own in 3 steps

1

Clone or download this repo

Grab the web/ folder from the GitHub repository — it's a complete, self-contained project.

2

Install dependencies

Run npm install inside the web/ folder.

3

Start it or deploy it

Run npm start to try it locally, or push to GitHub and import the repo on Vercel for an instant public URL.
